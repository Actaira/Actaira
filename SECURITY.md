# Security policy

## Reporting a vulnerability

Please do not open a public issue. Write to actairasolutions@gmail.com with what you found, how to reproduce it, and the version you used (`actaira version`).

## Supported versions

There is no release yet. Until the first one, fixes only go to the `main` branch.

## En español

No abras un issue público. Escribe a actairasolutions@gmail.com con lo que has encontrado, cómo reproducirlo y la versión que usaste (`actaira version`). Todavía no hay ninguna versión publicada: hasta la primera, las correcciones solo van a la rama `main`.
